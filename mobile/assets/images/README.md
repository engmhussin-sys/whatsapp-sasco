## خطوة إلزامية أخيرة — يجب تشغيلها محليًا

هذه الأوامر تُولِّد فعليًا كل أحجام أيقونة Android/iOS من الملفات أعلاه —
لا يمكن تنفيذها إلا على جهازك (تحتاج Flutter SDK مُثبَّتًا):

```bash
cd mobile
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

بعدها، احذف التطبيق من الهاتف قبل إعادة التثبيت (أندرويد يُخزِّن الأيقونة
القديمة مؤقتًا حتى مع رمز تطبيق جديد تمامًا).
