# ملفات الشعار المطلوبة (SASCO)

هذا المجلد يحتاج 3 ملفات صور حقيقية من الشركة (لم تُنشأ هنا عمدًا — راجع
الملاحظة في الرد الرئيسي حول عدم توليد نسخة مُلفَّقة من شعار SASCO الرسمي):

| الملف | المقاس المطلوب | الاستخدام |
|---|---|---|
| `app_icon.png` | 1024×1024px، خلفية غير شفافة | أيقونة التطبيق (Android/iOS) |
| `app_icon_foreground.png` | 1024×1024px، **خلفية شفافة**، الشعار في المنتصف بمساحة هامش كافية | الطبقة الأمامية لأيقونة Android التكيّفية (Adaptive Icon) |
| `splash_logo.png` | ~512×512px، **خلفية شفافة** | شاشة البداية (Splash Screen) |

## بعد إضافة الملفات الثلاثة، شغّل:

```bash
cd mobile
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

هذا يُولِّد تلقائيًا كل أيقونات Android/iOS بمختلف الأحجام + شاشة البداية
المُخصَّصة بلون SASCO الأخضر المؤسسي (`#0C7C42`) كخلفية، بناءً على الإعداد
الموجود في `pubspec.yaml`.

## إن لم يتوفر الشعار الرسمي بعد
التطبيق يعمل ويُبنى بشكل طبيعي تمامًا بدون هذه الملفات — فقط ستظهر أيقونة
Flutter الافتراضية مؤقتًا بدل شعار SASCO حتى تُضاف الملفات وتُشغَّل الأوامر
أعلاه.
